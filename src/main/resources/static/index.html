Spring Boot & MariaDB REST Endpoints Reference

GET /api/tasks

Fetch all tasks from MariaDB. Supports optional query filters: search, status, priority.

GET /api/tasks/{id}

Retrieve single task by numeric ID from MariaDB.

POST /api/tasks

Create a single task with JSON payload {title, description, status, priority}.

POST /api/tasks/batch

Batch insert multiple tasks at once into MariaDB with JSON array payload [{...}, {...}].

PUT /api/tasks/{id}

Update existing task in MariaDB with validated JSON payload.

PATCH /api/tasks/{id}/status?status=COMPLETED

Quickly update status of a task.

DELETE /api/tasks/{id}

Remove task record from MariaDB.

GET /api/tasks/stats

Retrieve aggregated task counts by status.

GET /api/health

System health check: MariaDB connection status, product version, uptime, JVM memory, and thread metrics.
